# Juego Piedra, Papel o Tijera en Python

## Objetivo del Programa

Desarrollar un programa interactivo en Python que permita simular el juego "Piedra, Papel o Tijera" entre un usuario y la computadora, aplicando conceptos fundamentales de programación como estructuras de control, manejo de datos, algoritmos y funciones.

## Funcionalidades Principales

El sistema implementa las siguientes funcionalidades:
- Visualización del título del juego en cada ronda
- Presentación de opciones disponibles (piedra, papel o tijera)
- Captura de la elección del usuario mediante entrada por teclado
- Validación de datos ingresados para evitar errores
- Generación aleatoria de la jugada de la computadora
- Comparación de elecciones para determinar el resultado
- Indicación del resultado (ganar, perder o empate)
- Opción de repetir el juego múltiples veces
- Finalización del programa según decisión del usuario

## Estructura del Programa

El programa está diseñado bajo un enfoque modular utilizando funciones:
- mostrar_titulo(): Muestra el encabezado del juego
- mostrar_opciones(): Presenta las opciones disponibles
- obtener_eleccion_usuario(): Captura y valida la entrada del usuario
- obtener_eleccion_computadora(): Genera una opción aleatoria
- determinar_ganador(usuario, computadora): Evalúa el resultado del juego
- jugar(): Controla el flujo general del programa

## Tecnologías Utilizadas
- Python (lenguaje de programación)
- Visual Studio Code (editor de código)
